<h2>🚀 Quick Start & Installation</h2>
<blockquote>
  <p>💡 <b>Note:</b> Ensure you have Node.js installed and your MongoDB URI ready in a <code>.env</code> file before starting.</p>
</blockquote>

```bash
# 1. Clone the repository
git clone [https://github.com/yourusername/ecommerce-dashboard.git](https://github.com/yourusername/ecommerce-dashboard.git)

# 2. Navigate into the directory
cd ecommerce-dashboard

# 3. Install Server Dependencies & Start Server
cd server
npm install
npm start

# 4. Install Client Dependencies & Start Client (in a new terminal)
cd ../client
npm install
npm start
